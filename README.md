# loessieraden.nl

Statische site over sieraden, gebouwd met een Python-generator zonder afhankelijkheden.

- `python3 build.py` schrijft de site naar `dist/`
- `python3 check.py` controleert interne links, meta, ankerteksten en taalgebruik

Cloudflare Pages: build command `python3 build.py`, output directory `dist`.
